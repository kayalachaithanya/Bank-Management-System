# 🏦 Bank Management System
## 📌 Project Overview
A console-based **Bank Management System** developed using **Java and Object-Oriented Programming (OOP)** concepts.

This project simulates basic banking operations such as creating accounts, depositing money, withdrawing money, transferring money, checking balance, viewing transaction history, and calculating interest.

---

## 🚀 Features

- Create Savings Account
- Create Current Account
- View Account Details
- Check Account Balance
- Deposit Money
- Withdraw Money
- Transfer Money
- View Transaction History
- Calculate Savings Account Interest
- Current Account Overdraft
- Display All Bank Accounts
- Account Number Masking
- Phone Number Masking
